# Code of Conduct

## Our standards

Participants are expected to be respectful, constructive, inclusive, and
professional. Harassment, discrimination, personal attacks, and deliberately
disruptive behavior are not acceptable.

## Reporting

Report unacceptable behavior privately to the repository maintainers through
the contact method listed in the repository profile. Do not include sensitive
credentials or private user data in public issues.

Maintainers may remove comments, close discussions, or restrict participation
when this code of conduct is violated.
